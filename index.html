OPEN SOURCE · ANDROID ALPHA

A personal AI assistant.
Starting on Android.

AI that feels like second nature.

Halo is an open-source AI assistant for Android today, built around a portable runtime for future hosts. Ask by voice or text, try supported phone actions, save notes, files and voice memos in Notebook, arrange them on Canvas, and learn from selected sources in Study. Choose a compatible on-device model, your own network server or an optional cloud provider. Glasses are optional. This alpha still has unverified workflows.

02 · PHONE ACTIONS

Ask Halo to help with a phone task.

Try setting a timer, opening an app or adjusting a setting. With permission and approval, Halo can also work with visible screen controls. Multi-step actions and handoffs to third-party apps are still being tested.

Control the phone

Set alarms and timers. Change volume, ringer mode, brightness and flashlight. Open settings and apps.

Examples: “Set a timer for 12 minutes.” · “Put the phone on vibrate.”

Navigate and communicate

Find contacts, open the dialer, launch navigation, open URLs, search the web, share text and control media.

When an action is handed to another app, Halo reports that the request was dispatched. Completion may still be unconfirmed.

Read useful context

Inspect device, battery and network state; read clipboard text; fetch a web page; search files and Notebook.

Access to sensitive data follows tool policies and approval rules.

Work with the screen

Read the current Android screen, find UI elements, and use accessibility-backed click, scroll and text entry when needed.

Screen-changing accessibility actions are explicitly confirmation-gated.

HONEST ACTION STATUS

A request is not proof it worked.

Halo records attempted actions and their outcomes. If another app takes over or Android cannot confirm the result, the assistant should report that rather than claim the task is finished.

03 · NOTEBOOK AND STUDY

Notes, files and study tools in one place.

Notebook saves notes, files and voice memos. Canvas connects and annotates selected material; Study creates lessons from chosen sources. Adding something to the workspace does not automatically share it with AI.

Notebook

Find your notes, imported files and saved conversations in one library. Choose the materials you want to work with next.

Canvas

Arrange notes, images, PDFs and recordings as source-linked cards. Draw, annotate, search, and review suggested arrangements before accepting them. Check imported or extracted content against the source.

Study

Set a learning goal, select material, then try guided explanations and practice. Lessons can track attempts and reviews; AI feedback and image understanding depend on the selected model.

You choose what the assistant uses

Working context

Adding an item to working context gives Halo material for the current task. You can add or remove items deliberately.

Memory

Saving a note does not save it as a memory. Keeping something in memory is a separate choice that requires your approval.

04 · AI OPTIONS

Choose where Halo thinks.

Download and test a model on your phone, connect a server on your network, or configure a cloud provider. Remote requests can send relevant context to the provider you select. Halo must not silently move your data to a different provider after a failure.

On this phone On your network In the cloud

ON DEVICE

LiteRT-LM

In Settings → Intelligence → On device, discover compatible LiteRT candidates, download one, test a reply, and explicitly select it for supported roles. A device-fit estimate is not proof that the model will run successfully on your phone.

ON YOUR NETWORK

Local model server

Connect to Ollama, OpenCode Companion or a compatible endpoint on a computer you control.

CLOUD

Optional cloud AI

Configure OpenRouter, Gemini, OpenAI or another supported provider. Each service has its own setup, costs and limits.

Gemini can use Google OAuth.

The current app supports Google authorization with a Cloud project, alongside an API-key fallback.

Some providers offer free-tier options.

Free access, model availability and limits depend on the provider and may change.

Your provider choice is respected.

A selected provider failure is not permission to silently move private context to another provider.

Credentials are protected.

Credentials use Android Keystore-backed storage rather than ordinary app preferences.

Find the setting you need.

  • Intelligence — providers, model library and local models
  • Voice — speech input, playback and output devices
  • Privacy & Permissions — data choices and Android access
  • Advanced — diagnostics and runtime details for testers

The design book depicts the intended organization of Settings. The Android implementation is evolving; exact names and availability can differ by build.

05 · CONNECTED DEVICES

Start on Android. Other devices are optional.

Android works as a standalone host. Devices shows the phone first, then optional glasses, headsets and experimental hardware. A listed capability is not proof that a device is connected or permitted to act.

FIRST HOST PLATFORM

Android phone

The Android app includes Home, Activity, Notebook, model and voice setup, supported phone tools, and Study. New layouts and device-sensitive workflows still need hands-on validation.

TEST HARDWARE

HeyCyan glasses

HeyCyan glasses are an active Bluetooth and microphone integration target. Pairing and basic device status have dedicated screens; speaker routing and media paths still need hands-on verification.

AUDIO ACCESSORIES

Headsets and earbuds

Supported Android headsets can provide microphone and audio output, depending on routing and permissions.

EXPERIMENTAL HARDWARE

BuddyBot

BuddyBot is a robot project exploring physical actions and safety. It is experimental and not needed to use Halo.

PHONE ABILITIES

Seven groups you can inspect.

Devices now groups the phone's reported capabilities into categories. “Available” means the runtime reported a capability; it is not a grant to read private information or control the phone. Permissions and confirmations remain separate.

  • Hear and speak
  • See and use the screen
  • Phone controls
  • Apps and the web
  • Calendar and contacts
  • Notifications
  • Clipboard and Notebook

Pairing happens in steps.

Allow nearby-device access if Android asks, search for powered-on glasses, select the right result, then connect. A successful connection does not automatically start recording, camera capture or audio routing.

06 · DEVELOPMENT STATUS

A real alpha, not a finished product.

Android includes real implementations and automated tests, but compile checks, unit tests and physical device acceptance are different things. Recent Devices, pairing, Settings, brand presence, Kids Mode and model workflows have not all passed comprehensive testing on physical devices. Check GitHub Releases for supported builds and known limits.

TESTED ON HARDWARE

A local model has answered on a phone.

A small Qwen model has produced local responses on an Android test device. HeyCyan microphone capture also has real-hardware evidence.

AUTOMATED CHECKS

Automated tests cover core paths.

The app has code-level tests for actions, workspace and model-related behavior. Passing tests does not establish that every command works on every phone.

NEEDS END-TO-END TESTING

07 · HOW HALO WORKS

One runtime, different devices and models.

Halo separates input, context, model reasoning, permissions and tool execution. Android is the first host; Linux and Windows are development targets, not released apps. The aim is to keep the assistant useful without committing to a single model or gadget.

OUR PURPOSE

          
An assistant that fits into your day.

          
Halo brings together everyday requests, supported phone actions, notes and learning on Android. You decide which sources and permissions it can use, and whether a request goes to an on-device model or a service you select.

        

        

          

            
            
On-device first

            
A compatible model can answer on your phone after you download and test it. Available memory, performance and supported languages depend on the device and model.

          

          

            
            
Open source

            
The opening in the ring stands for an open project. The Android app, runtime and website can be examined and improved by contributors.

          

          

            
            
Your data stays yours

            
Your files stay local unless you choose an action or provider that shares information. Review permissions and the privacy terms of any service you connect.
