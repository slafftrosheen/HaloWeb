Halo is a personal cognitive runtime, not a wrapper around one model or one device. The Android host can run local inference, keep a persistent workspace, act through system capabilities and extend the same interaction to connected hardware.

01 · PRODUCT

A real Android host.
Not a wearable companion screen.

The product starts on the phone. Wearables and physical devices extend its reach; they do not own the intelligence, workspace or runtime.

The repository does not yet contain committed emulator/device captures for these screens. These are static screenshot assets reconstructed from the current Compose source—not interactive HTML mockups.

PORTABLE CONTRACTS

Capabilities, not brand checks.

Tools declare semantic requirements. Phones, glasses, watches and robots publish what they can actually do.

DURABLE EXECUTION

Action truth survives the UI.

Approvals and tool outcomes are journaled so a hidden surface, restart or retry does not rewrite what actually happened.

RESOURCE OWNERSHIP

One camera. One microphone. Explicit arbitration.

The runtime coordinates scarce host and wearable resources instead of letting features silently fight over them.

03 · NOTEBOOK

04 · LOCAL AI

On-device is the default.
Network access is explicit.

Halo's embedded local provider now uses LiteRT-LM. The clean-install path is a packaged .litertlm model with GPU→CPU fallback.

ProviderWhere it runsRoleNetwork
LiteRT-LMprovider.litert.local Android host Default on-device inference Not required
Ollamaoptional Local network host LAN inference LAN
OpenRouteroptional Remote provider Cloud model access Internet

No silent provider substitution. The selected provider is part of the interaction contract; local-only policy remains explicit.

05 · DEVICES

Same runtime.

06 · DIRECTION

Android is the first host.
The runtime is the product.

NOW

Make the Android host undeniable.

System assistant, LiteRT local inference, Notebook workspace, device fabric, tools and hardware acceptance.

NEXT

Linux, Windows and dedicated compute without rebuilding the cognitive layer around a new platform.
