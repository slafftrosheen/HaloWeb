NOTE

Halo interface notes

LOCAL · AUTOSAVED

The Signal Face is the single visual identity for runtime state. Pixel glyphs carry the same meaning into navigation, devices and compact surfaces.

Principle: a surface may disappear. The runtime and the user's work should not.

04 / LOCAL-FIRST

Local is the default path.
Network is an explicit capability.

Halo does not require a Halo cloud or Halo account. Native llama.cpp is the clean-install inference path; LAN or cloud providers remain user-selected options.

05 / DIRECTION

Phone first.
Runtime everywhere.

The product is deliberately staged. The website should make that boundary visible rather than making tomorrow look shipped today.

NOW

Android host

Voice/text interaction, local provider path, Notebook, device management, runtime actions and diagnostics.

NEXT

Wearable continuity

Generalized wearable capabilities, stronger hardware acceptance, durable context and reliable assistant actions.

LATER

More hosts

Linux, Windows and broader physical embodiments without redesigning the runtime around any one host.

Experimental

Embodiment

BuddyBot remains a physical Halo host track — useful for proving capability, safety and action contracts without redefining Halo as a robot project.
