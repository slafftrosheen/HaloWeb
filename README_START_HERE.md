# Halo Alpha - Quick Test Kit

**Time:** about 15-25 minutes. **Audience:** alpha testers without their own test files.

## What is included

- `01_study_basil_observation.png` - image with exact invented measurements (tests actual image understanding).
- `02_study_how_light_affects_plants.pdf` - searchable/selectable-text science reading, meant for PDF parsing.
- `03_halo_alpha_quick_test.pdf` - 10 steps through main Halo areas, with expected behavior.
- `04_sample_note.txt` - harmless text for Notebook import or manual note creation.
- `05_copy_paste_prompts.txt` - ready test prompts and expected answers; supports issue reporting.

## Recommended route

Follow the 10 actions in the quick-test PDF. Start with Home/Notebook, then Study PDF and image. Voice and physical devices are explicitly optional. Skip blocked functions and report why, rather than entering real accounts, secrets, or private files just to finish the test.

## Why both an image and a PDF?

The PDF describes the experiment, watering schedule, and scientific reasoning. It deliberately **does not contain final height measurements**. Those numbers appear in the PNG. This lets testers catch a generic answer masquerading as document reading or vision.

### Answer key (invented sample data)

- PDF watering: six days (1, 3, 5, 7, 9, 11), 50 mL each, **300 mL per pot** in total.
- Image final heights: A **6 cm**, B **10 cm**, C **14 cm**. C is **8 cm** taller than A.
- All began **4 cm** tall, so gains are **2 / 6 / 10 cm** (A / B / C).
- Changed variable: light **2 / 6 / 10 h/day**. Same basil type, starting height, pot size, soil, watering.
- This single fictional example does not establish a universal scientific law. A good tutor should say so.

## Feedback

Mark each route step PASS / ISSUE / SKIP. For any issue: the action, expected outcome, actual result, and screenshot/log (after removing personal data, API keys, and device identifiers). Testers may use English, Russian, or Latvian.

**Important:** All observations and numeric results in this kit are simulated, not a real plant experiment.
