Try the Android alpha and tell us what happened.

Install the pre-release build, follow guided setup, and use the sample files and short checklist below. Report failed or confusing steps — even if you couldn’t finish setup. No glasses or personal files needed.

Halo for Android · v0.1.0-alpha.2

Pre-release · published 15 October 2026 · debug-signed APK on GitHub Releases. Android only.

Open Android releases

A public build exists only when it appears on GitHub Releases. There is no desktop or Linux download yet.

Four steps.

  1. 01

    Get Halo

    Open Android releases. No published APK? The app isn’t available through this programme yet.

  2. 02

    Grab the test kit

    One short reading, one observation image, and a quick route through the wider app.

  3. 03

    Try real workflows

    Use the checklist, skip hardware you don’t own, and note what actually happens.

  4. 04

    Share a finding

    Report confusing moments as well as broken features. Both help shape Halo.

Free sample files

Five downloadable test files.

Start with the guide, then import the other files into Halo as needed. The Study example follows three basil seedlings with different daily light, so you can check whether Halo uses the source or invents a plausible answer. Files are in English.
