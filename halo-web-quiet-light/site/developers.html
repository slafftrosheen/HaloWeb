Built in the open.

Halo is a portable runtime with a host for each platform. Android is the first host; Linux is next. Here’s how the pieces fit, and where to start.

Architecture

One runtime, many hosts.

Hosts
AndroidLinuxWindows
Host adaptersPlatform services: audio, storage, permissions, phone actions, devices.
RuntimeConversation, tool use with approval, honest receipts, recovery after a crash, durable agent runs.
Workspace & memoryNotebook, Canvas, Study and approved memory, stored locally with search.
Provider routingOn-device (LiteRT), your own server (OpenAI-compatible), or a cloud provider you configure — per job.
Peer nodesPrivate identity, pairing and sync between your devices.Planned

Contribute

Reports are contributions.

The most useful thing right now is careful testing on real phones: what you tried, what you expected and what actually happened.

Report on GitHub Tester kit

Before you open an issue

Include your Halo and Android versions, the screen, the steps, and what happened. Never post API keys, personal files, identifiers or private logs.

Code changes: read the engineering notes in docs/ first — they explain which parts are tested and which aren’t.
